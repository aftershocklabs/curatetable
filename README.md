# 🍽️ CurateTable

> AI-Powered Dinnerware Configurator for Restaurants

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## What is CurateTable?

CurateTable helps restaurant owners make smarter dinnerware purchasing decisions. Using AI, it analyzes your restaurant's concept, location, menu, and budget to recommend the perfect tableware — then generates a custom-branded PDF catalog ready for ordering.

## How It Works

```
1. 💬 Tell us about your restaurant
   "Mexican cantina in Brooklyn, 50 seats, $2k budget"

2. 🤖 AI analyzes your needs
   Location demographics, menu style, budget optimization

3. 📄 Get personalized recommendations
   Custom PDF catalog with your branding

4. 📧 One-click delivery
   Email to sales rep or create SAP quotation
```

## Features

- 🗣️ **Natural Language Input** — Just describe your restaurant
- 📍 **Location Intelligence** — Google Maps integration for demographics
- 🍽️ **Menu Matching** — Recommendations based on cuisine type
- 💰 **Budget Optimization** — Best value within your constraints
- 📄 **Custom PDF Catalogs** — Branded with your logo
- 🔄 **Reorder Recommendations** — Know when to resupply

## Tech Stack

- **Frontend:** Next.js 14, Tailwind CSS, shadcn/ui
- **Backend:** Next.js API Routes, PostgreSQL
- **AI:** OpenAI / Claude
- **APIs:** Google Maps, PDF Generation

## Getting Started

```bash
# Clone the repo
git clone https://github.com/aftershocklabs/curatetable.git

# Install dependencies
pnpm install

# Set up environment variables
cp .env.example .env.local

# Run development server
pnpm dev
```
